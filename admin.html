Publish to the live site

"Save changes" only keeps a draft in this browser. Publish sends your text, colors, work and any uploaded images to GitHub, so visitors on every device see them about a minute later.

One-time setup: create your access token

  1. On github.com click your profile picture → Settings → scroll down to Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "portfolio admin" and set an expiry (90 days is sensible).
  3. Under Repository access choose Only select repositories and pick portfolio-v1.
  4. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else alone.
  5. Click Generate token, copy it (it starts with github_pat_) and paste it above. It's only shown once.

The token stays in this browser only — it is never put in the website's code or the repo. It's the real lock: without it nobody can publish. Don't use it on a shared computer, and if it ever leaks, delete it on GitHub and make a new one.
